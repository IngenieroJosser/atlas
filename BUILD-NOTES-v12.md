# ATLAS v12 — VORON Crafted UI

## Cambios principales

- Design System completamente revisado.
- Manrope para títulos/headings mediante `AtlasFontRegistry`.
- Geist para interfaz/body/metadata mediante `AtlasFontRegistry`.
- Fallback automático a SF Pro/System Rounded si las fuentes no están presentes.
- Home reconstruida con World Hero, métricas integradas y composición editorial.
- Asset Detail reconstruido con identidad visual tipo blueprint y lectura progresiva.
- Onboarding y Login reconstruidos.
- Bottom Navigation refinada.
- Asset rows, changes, inspections, evidence, alerts, AI insight y comparison rediseñados.
- Light/Dark Mode conservado.
- Cámara, Vision, ARKit capability detection y motion system preservados.

## Fuentes

Colocar los archivos locales del usuario en:

ATLAS/Resources/Fonts/Manrope-VariableFont_wght.ttf
ATLAS/Resources/Fonts/Geist-VariableFont_wght.ttf

También se incluye `Scripts/install-local-fonts.sh` para copiarlos desde Downloads/Desktop cuando coincidan los nombres.
